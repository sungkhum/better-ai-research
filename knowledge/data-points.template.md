# Data Points

Hard numbers, statistics, and quantitative findings accumulated across all research projects. Every data point includes its source and the project that discovered it.

**Rules**: Append new data points at the end. Never edit or remove existing entries. If a data point is superseded by newer data, add the new entry and note it updates the old one. Always include source attribution.

## Entry Format

```
## Brief Descriptor
- **Claim**: Specific factual claim with number/date/unit
- **Source**: Citation with tier (e.g., "World Bank, Tier 1" or [[source-file]])
- **Confidence**: High / Medium / Low
- **Context**: Brief context for why this number matters
- **First encountered**: [[projects/YYYY-MM-DD-topic-slug/README]]
- **Date added**: YYYY-MM-DD
```
