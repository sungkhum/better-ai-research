# Research Frameworks

How to approach different types of research questions. Read this BEFORE starting any research to pick the right structure.

## Framework Selection

### Type 1: "Is X true?" (Verification)
- Start with [[technical]] lens to establish what the data actually says
- Then [[contrarian]] to stress-test the claim
- Then [[historical]] for precedent
- Best for: fact-checking, debunking, validating assumptions
- Example: "Is nuclear fusion viable by 2035?"

### Type 2: "Why is X happening?" (Causal Analysis)
- Start with [[historical]] to trace the roots
- Then [[economic]] to find incentive structures
- Then [[technical]] for mechanism
- Then [[geopolitical]] for systemic forces
- Then [[contrarian]] to challenge your causal chain
- Then [[first-principles]] to check if the whole model holds
- Best for: understanding trends, explaining phenomena
- Example: "Why are birth rates collapsing globally?"

### Type 3: "What happens if X?" (Scenario Planning)
- Start with [[first-principles]] to establish base assumptions
- Then [[technical]] for constraints
- Then [[economic]] for incentives
- Then [[geopolitical]] for power dynamics
- Then [[historical]] for analogous scenarios
- Then [[contrarian]] for the scenario nobody expects
- Best for: forecasting, strategy, decision-making
- Example: "What happens to Europe if birth rates stay below replacement for 30 years?"

### Type 4: "What should I do about X?" (Decision Support)
- Run all 6 lenses in parallel
- Rank options by lens agreement (if 5/6 lenses point the same way → high confidence)
- Flag where lenses diverge — those are the real decision points
- Best for: investment decisions, policy, strategy
- Example: "Should we invest in desalination technology?"

## Research Depth Levels

### Quick Scan (30 min)
- 3 lenses maximum — pick the most relevant for this question type
- Top 5 sources only
- Goal: directional understanding, not certainty
- Output: executive summary only

### Standard Research (default)
- All 6 lenses
- 15-25 sources across lenses
- Cross-reference findings between lenses
- Goal: informed opinion backed by evidence
- Output: all 4 output documents

### Deep Dive
- All 6 lenses with sub-questions per lens
- 50+ sources including primary data
- Full contradiction resolution required
- Interview/expert source integration when available
- Goal: publishable analysis, decision-grade intelligence
- Output: all 4 output documents + detailed source evaluations

## Source Collection Strategy

For each lens:
1. Start with the BEST single source (see [[source-evaluation]])
2. Find the source that DISAGREES most with #1
3. Find primary data that lets you judge between them
4. Record everything in [[data-points]] with attribution

## Choosing Between Frameworks

If your question doesn't fit neatly:
- Identify the PRIMARY intent (verify? explain? predict? decide?)
- Use that framework's lens ordering
- Add extra lenses from other frameworks if relevant
- Note your framework choice in the project README so future sessions understand the approach
