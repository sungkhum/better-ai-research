# Example Project: Why Are Birth Rates Collapsing Globally?

This is an example showing the structure of a completed research project. When you run your first real research question, Claude will create a folder like this automatically.

## Project Info
- **Date**: 2026-04-15
- **Status**: example (not real research)
- **Framework**: Type 2 — Causal Analysis (from [[research-frameworks]])
- **Depth**: Standard Research
- **Question**: Why are birth rates collapsing globally, and what are the likely consequences?
- **Scope**: Global trends with focus on OECD countries, 1960-present
- **Output Goal**: Understand root causes and assess common policy responses

## Expected Output Files

A completed project would contain:

| File | Purpose |
|------|---------|
| `lens-technical.md` | Fertility rate data, demographic projections, measurement methodology |
| `lens-economic.md` | Cost of child-rearing, housing, opportunity cost analysis, policy ROI |
| `lens-historical.md` | Demographic transitions, baby boom/bust cycles, historical parallels |
| `lens-geopolitical.md` | Country comparisons, immigration as policy tool, pension system strain |
| `lens-contrarian.md` | "Is low fertility actually a crisis?" — challenges to the panic narrative |
| `lens-first-principles.md` | Why do organisms reproduce? What changed in the incentive structure? |
| `synthesis.md` | Cross-lens analysis, agreement/tension maps, confidence calibration |
| `executive-summary.md` | 500-word summary with the single most important insight |
| `deep-dive.md` | Full report organized by lens with cross-references |
| `key-players.md` | Countries, institutions, researchers, and policymakers that matter |
| `open-questions.md` | What we still don't know — seeds for future research |

## How the Lenses Would Interact

The power of this system is in the tensions between lenses:

- **Technical** says: "The math is brutal — at 1.2 TFR, South Korea's population halves in 45 years"
- **Contrarian** says: "Japan has had low fertility for 50 years and hasn't collapsed"
- **Economic** says: "Every financial incentive tried so far has had minimal effect"
- **First Principles** says: "This suggests the drivers are cultural/identity-based, not economic"

Neither lens is wrong. The truth lives in the tension between them.

## Knowledge Capture

After completing research, new entries would be appended to:
- [[concepts]] — demographic transition, total fertility rate, dependency ratio, etc.
- [[data-points]] — specific fertility rates by country, policy cost/effectiveness data
- [[research-log]] — dated entry linking back to this project folder
