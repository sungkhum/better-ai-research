# Research Log

Chronological record of all research projects. Append new entries at the end after completing a project.

Each entry links to the project folder and captures key findings so future research can build on past work.

## Entry Format

Use this structure for each entry:

```
## YYYY-MM-DD: Topic Title
- **Question**: The research question
- **Framework**: Which type from [[research-frameworks]] (Verification / Causal / Scenario / Decision)
- **Depth**: Quick Scan / Standard / Deep Dive
- **Lenses applied**: which lenses were used
- **Key findings**: 2-3 bullet summary of the most important insights
- **Key tension**: the most productive contradiction between lenses
- **Open questions**: top 1-2 unresolved questions (seeds for future research)
- **Project folder**: [[projects/YYYY-MM-DD-topic-slug/README]]
- **Concepts added**: list of new concepts appended to [[concepts]]
- **Data points added**: count of new entries in [[data-points]]
```
