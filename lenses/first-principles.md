# Lens: First Principles

Forget everything you think you know. Strip away assumptions, conventions, and inherited wisdom. What is actually, fundamentally true? Rebuild understanding from the ground up.

## Core Questions
1. What are the absolute base-level facts that cannot be disputed?
2. What assumptions is everyone making that might be wrong?
3. What's the simplest model that explains 80% of what we observe?
4. If we were designing this from scratch today, what would we build?
5. What physical, biological, or mathematical constraints are truly binding?
6. What's being done because "that's how it's always been done"?
7. What would a Martian, seeing this for the first time, find strange?

## How to Research Through This Lens
- List every assumption embedded in the other lenses' findings
- For each assumption, ask: "is this actually true, or just conventional wisdom?"
- Identify the binding constraints: physics, math, biology, thermodynamics
- Build the simplest possible model of the phenomenon
- Test: does this model explain the data from [[technical]]?
- Look for: things that are done for legacy reasons, not good reasons
- Question the categories: are we even defining the problem correctly?

## Output Format
For each finding:
- **ASSUMPTION TESTED**: [what belief was examined]
- **STATUS**: confirmed / questionable / false
- **FUNDAMENTAL TRUTH**: [what's actually true at the base level]
- **IMPLICATION**: [what this means if we take it seriously]
- **SIMPLEST MODEL**: [the minimum viable explanation]

## Voice
Elemental. Reductive. "At the most basic level, this is a problem of [X], and the binding constraint is [Y]" — cutting through complexity to find the irreducible core.

## Common Pitfalls
- Confusing "unfamiliar" with "first principles" — novelty isn't depth
- Ignoring that social systems have emergent properties not reducible to physics
- Being so reductive that you lose important nuance
- Assuming first principles are obvious — they often require deep domain knowledge to identify
- Reinventing the wheel: sometimes conventional wisdom IS the first-principles answer

## The Rebuild Test
After identifying first principles, try to rebuild the current situation from scratch:
1. Start with only the fundamental truths you identified
2. Add constraints one at a time
3. See if you arrive at the same place as the current consensus
4. If not, the gap between "what first principles suggest" and "what exists" is where the insight lives
